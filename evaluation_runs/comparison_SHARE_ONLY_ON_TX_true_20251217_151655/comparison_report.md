# NEIGHBORS_ONLY vs REQUEST_BASED 比較評価レポート（伝播時間のみ）

生成日時: 2025-12-17 15:18:03

## 概要

本レポートは、本番シナリオ（共有ONのみ、FORERUNNER_SHARE_ONLY_ON_TX=true）において、NEIGHBORS_ONLYモードとREQUEST_BASEDモードの伝播時間を比較したものです。

## 評価指標

1. **ブロック伝播時間**: ブロックが最初のノードから最後のノードまで伝播するのに要する時間
2. **ネットワーク効率**: ブロックがネットワークを拡散する際の平均進行速度
