# ホップ数設定の現状と実装方法

## 現在の実装状況

### ❌ 現在はホップ数設定が実装されていません

現在のコードでは、以下のような状況です：

1. **NEIGHBORS_ONLY**: 常に1ホップ先のみ（固定値）
   ```java
   case NEIGHBORS_ONLY:
     return getNeighborNodes();  // 1ホップ先のみ
   ```

2. **CUSTOM_BROADCAST_RANGE環境変数**: 存在するが未実装
   - 環境変数`CUSTOM_BROADCAST_RANGE`は定義されている
   - しかし、`getCustomRangeNodes()`メソッドでは実際には使用されていない
   ```java
   private List<Node> getCustomRangeNodes() {
     // CUSTOM_BROADCAST_RANGE環境変数を読み取るが...
     String customRangeStr = System.getenv("CUSTOM_BROADCAST_RANGE");
     // 実際には単に隣接ノードを返すだけ
     customNodes = getNeighborNodes();
   }
   ```

3. **getSlowNodes()**: 2ホップ先まで取得する実装があるが、固定値
   - `SLOW_NODES_ONLY`モードで使用される
   - 環境変数で制御できない

## 実装方法（提案）

### 方法1: 環境変数で設定（推奨）

ユーザーの例のように、環境変数でホップ数を設定できるようにします：

```bash
export BROADCAST_SCOPE=NEIGHBORS_ONLY
export NEIGHBORS_HOP_COUNT=1  # または 2
```

### 実装コード例

```java
/** 隣接ノードのホップ数を取得 */
private int getNeighborsHopCount() {
  String hopCountStr = System.getenv("NEIGHBORS_HOP_COUNT");
  if (hopCountStr != null && !hopCountStr.isEmpty()) {
    try {
      int hopCount = Integer.parseInt(hopCountStr.trim());
      return Math.max(1, Math.min(hopCount, 3)); // 1〜3ホップまで制限
    } catch (NumberFormatException e) {
      return 1; // デフォルトは1ホップ
    }
  }
  return 1; // デフォルトは1ホップ
}

/** ブロードキャスト範囲に応じて対象ノードを取得 */
private List<Node> getTargetNodesForBroadcast() {
  switch (broadcastScope) {
    case NEIGHBORS_ONLY:
      int hopCount = getNeighborsHopCount();
      if (hopCount == 1) {
        return getNeighborNodes();
      } else if (hopCount == 2) {
        return getNeighborsWithinTwoHops();
      } else {
        // 3ホップ以上の場合は拡張可能
        return getNeighborsWithinNHops(hopCount);
      }
    // ... 他のケース ...
  }
}
```

### 方法2: CUSTOM_BROADCAST_RANGEを活用

既存の`CUSTOM_BROADCAST_RANGE`環境変数を実装する：

```java
private List<Node> getCustomRangeNodes() {
  List<Node> customNodes = new ArrayList<>();
  
  try {
    String customRangeStr = System.getenv("CUSTOM_BROADCAST_RANGE");
    if (customRangeStr != null && !customRangeStr.isEmpty()) {
      int hopCount = Integer.parseInt(customRangeStr.trim());
      if (hopCount == 1) {
        return getNeighborNodes();
      } else if (hopCount == 2) {
        return getNeighborsWithinTwoHops();
      } else {
        return getNeighborsWithinNHops(hopCount);
      }
    }
  } catch (Exception e) {
    System.err.println("Warning: Error in custom range: " + e.getMessage());
  }
  
  return getNeighborNodes(); // デフォルトは1ホップ
}
```

使用方法：
```bash
export BROADCAST_SCOPE=CUSTOM_RANGE
export CUSTOM_BROADCAST_RANGE=2  # 2ホップ先まで
```

## 推奨実装方法

### オプションA: NEIGHBORS_HOP_COUNT環境変数を追加（推奨）

**メリット**:
- `NEIGHBORS_ONLY`モードで直接ホップ数を指定できる
- 直感的で分かりやすい

**実装**:
```java
case NEIGHBORS_ONLY:
  int hopCount = getNeighborsHopCount(); // 環境変数から取得
  if (hopCount == 1) {
    return getNeighborNodes();
  } else {
    return getNeighborsWithinNHops(hopCount);
  }
```

**使用方法**:
```bash
export BROADCAST_SCOPE=NEIGHBORS_ONLY
export NEIGHBORS_HOP_COUNT=2  # 2ホップ先まで
```

### オプションB: CUSTOM_BROADCAST_RANGEを実装

**メリット**:
- 既存の環境変数名を活用できる
- `CUSTOM_RANGE`モードで使用可能

**実装**:
```java
case CUSTOM_RANGE:
  return getCustomRangeNodes(); // CUSTOM_BROADCAST_RANGE環境変数を読み取る
```

**使用方法**:
```bash
export BROADCAST_SCOPE=CUSTOM_RANGE
export CUSTOM_BROADCAST_RANGE=2  # 2ホップ先まで
```

## 現在の設定方法（現状）

現在は、ホップ数を設定する方法は**存在しません**。

- `NEIGHBORS_ONLY`: 常に1ホップ先のみ（固定）
- `CUSTOM_BROADCAST_RANGE`: 環境変数は存在するが、実装されていない

## まとめ

**質問への回答**: 
現在、`hops = 1`のような形式でのホップ数設定は**実装されていません**。

**実装が必要な場合**:
1. `NEIGHBORS_HOP_COUNT`環境変数を追加する方法（推奨）
2. 既存の`CUSTOM_BROADCAST_RANGE`環境変数を実装する方法

どちらの方法でも、環境変数から数値を読み取ってホップ数を制御できます。
